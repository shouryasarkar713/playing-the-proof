# Figures

All PNGs are genuine screenshots of the production build (`vite build`) of the application, driven through real UI events (clicks, typed input, key presses, mouse clicks on the board) by `capture-figures.mjs` (puppeteer-core + system Chrome, headless). Nothing is composited or edited. Default: viewport 1280x800 CSS px, deviceScaleFactor 2 (2560x1600 PNG), light theme (`ptp-theme=light` in localStorage). Console messages, page errors and failed requests were recorded during capture: none occurred (`console-log.txt`).

Reproduce: build the app, serve it (e.g. `npx vite preview --port 4791`), then `npm i puppeteer-core` in a scratch directory and run `PTP_URL=http://localhost:4791/ PTP_OUT=<dir> node capture-figures.mjs [fig01 fig02 ...]`. Entry-screen cards are addressed by position (1 Proof, 2 Break, 3 Sandbox, 4 Lab, 5 k-strip explorer). In the k-strip explorer and Lab, the right-hand panel column scrolls independently of the page; where noted, it was scrolled to the named panel before capture.
